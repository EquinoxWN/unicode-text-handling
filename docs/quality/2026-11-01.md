# Quality check against the 10 rules (2026-11-01)

Checked on 2026-11-12, when M1 was built, on Windows 11 with Temurin 21.0.12.1, Maven 3.9.11,
Python 3.14.5 and Node.js 24.19.0. The code is pure text processing plus one downloader
(`spec/fetch_ucd.py`) and one generator (`spec/generate_vectors.py`).

## Rules

| # | Rule | Status | Evidence |
|---|---|---|---|
| 1 | Assume every call can fail | pass | The only external call is `fetch_ucd._open` (https only, 60 s timeout). `download` retries network errors 3 times with 1 s / 2 s backoff, never retries a checksum mismatch, and raises `FetchError` with the cause (`test_spec_tools.py`: retry, give-up and success-after-retry tests). No empty `catch`/`except`: `Mojibake.unwindOnce` (Java) and `unwindOnce` (JS) turn a UTF-8 decoding error into "not mojibake" by design and rethrow anything else in JS; ruff `BLE`, `S110`, `E722` are enabled. |
| 2 | Writes safe to retry | pass | Downloads go to a temp file in the target directory and `os.replace` it after the checksum passes; the generator writes through a temp file and rename (`write_atomic`). Re-running either gives identical files (`--check` exits 0 after a run). `test_checksum_mismatch_leaves_no_file`, `test_network_errors_are_retried_then_reported` assert no partial file remains. |
| 3 | No race conditions | N/A | No threads, async code or shared mutable state. Module-level tables (`DECODE`/`ENCODE`, `RANGES`, the JS `Intl.Segmenter`) are built once and only read. |
| 4 | Don't trust the clock | N/A | No durations or timestamps are measured or stored. Backoff uses `time.sleep` only. |
| 5 | Read before changing | pass | No environment variables are read by the code. One JVM system property, `uth.vectors`, is documented in the README and set by `pom.xml`. APIs used exist in the installed versions (`str.isWellFormed` in Node 24, `BreakIterator`/`\X` in JDK 21, `itertools.pairwise` in Python 3.10+). Every path in the README exists (`audit_repo.py` checks links). |
| 6 | Never break compatibility | pass | New repository; the vector file formats are documented in each file's header. Changing the Unicode version is a deliberate change through `fetch_ucd.py` (ADR 0002). |
| 7 | One source of truth | pass | `spec/vectors/*` and `_grapheme_data.py` are copies built from the pinned Unicode files; `generate_vectors.py --check` in `make lint` fails on drift. `encoding.tsv` and `known-deviations.tsv` are hand-written and are the single source for all three languages. Version 0.1.0 agrees in `pyproject.toml`, `__init__.py`, `package.json` and `pom.xml` (`0.1.0-SNAPSHOT`); Java 21, Python 3.11+ (CI 3.12) and Node.js 24 agree in README and CI. |
| 8 | Small changes, no secrets, validate input | pass | No secrets. Every public entry point validates its input: type (`TypeError` / `NullPointerException`), length (2,000,000 UTF-16 units in Java/JS, 1,000,000 code points in Python), lone surrogates rejected by `measure` and `garble`, `max_rounds` limited to 0..10. Vector loaders reject missing, oversized (> 4 MB) and malformed files with the file and line. Downloads are capped at 8 MB. |
| 9 | Tests that can actually fail | fixed | No skipped or assertion-free tests (`grep -rnE "assert True|assertTrue\(true|@Disabled|skip|xfail|todo"` on the test folders finds only the test name `test_fetch_all_skips_verified_files`). Harness tests feed broken implementations (no-op normalizer, swapped forms, a normalizer wrong on one column, a segmenter that drops or adds a cluster) and require failures. 21 hand mutations below; the one survivor was killed by a new test. |
| 10 | Re-verify | pass | `generate_vectors.py --check`: `vectors: 5 files, 5 already up to date`. `ruff check`, `ruff format --check`: clean. `mypy`: `Success: no issues found in 19 source files`. `mvn verify` (`-Xlint:all -Werror`): `Tests run: 110, Failures: 0, Errors: 0, Skipped: 0`. `pytest`: `170 passed`. `npm test`: `pass 99`, `fail 0`. pip-audit: `No known vulnerabilities found`. npm audit: `found 0 vulnerabilities`. `osv_audit.py Maven`: `8 dependencies checked, 0 with known vulnerabilities`. `audit_repo.py`: `unicode-text-handling: OK`. CI has not run yet (not pushed). |
